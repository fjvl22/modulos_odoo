INFORME TÉCNICO

Desarrollo de un módulo de gestión de veterinaria en Odoo

1. Introducción

El presente documento describe el desarrollo de un módulo personalizado en Odoo orientado a la gestión básica de una veterinaria. El objetivo principal ha sido implementar un sistema que permita la manipulación de datos mediante modelos, vistas y formularios, así como la realización de operaciones CRUD (Create, Read, Update, Delete).

El módulo desarrollado permite gestionar información sobre mascotas y sus respectivos dueños, estableciendo una relación estructurada entre ambas entidades.

2. Objetivos

Los objetivos del desarrollo han sido los siguientes:

* Crear un módulo funcional en Odoo desde cero
* Definir modelos de datos personalizados
* Implementar relaciones entre entidades
* Desarrollar vistas tipo lista y formulario
* Realizar pruebas de inserción, lectura y actualización de datos
* Documentar el proceso y los resultados obtenidos

3. Estructura del módulo

El módulo desarrollado, denominado *“veterinaria”*, sigue la estructura estándar de Odoo:

* models/: contiene la definición de los modelos de datos
* views/: incluye las vistas XML (formularios y listas)
* security/: define los permisos de acceso
* manifest.py: archivo de configuración del módulo

Esta organización permite separar claramente la lógica de datos, la interfaz y la seguridad.

4. Modelado de datos

Se han definido dos modelos principales:

4.1 Modelo Dueño

Representa a los propietarios de las mascotas.

Campos:

* Nombre
* Teléfono
* Email

Además, incluye una relación:

* One2many → lista de mascotas asociadas

4.2 Modelo Mascota

Representa a los animales registrados en la veterinaria.

Campos:

* Nombre
* Especie (perro, gato, otro)
* Edad
* Observaciones

Incluye una relación:

* Many2one → referencia al dueño

5. Relación entre entidades

Se ha implementado una relación bidireccional entre los modelos:

* Un dueño puede tener varias mascotas (One2many)
* Cada mascota pertenece a un único dueño (Many2one)

Esta relación permite mantener la integridad de los datos y facilita la navegación entre registros.

6. Vistas e interfaz de usuario

Se han desarrollado las siguientes vistas:

6.1 Vista tipo lista (tree)

Permite visualizar múltiples registros de forma tabular, mostrando los campos más relevantes.

6.2 Vista tipo formulario (form)

Permite la creación y edición de registros individuales mediante formularios estructurados.

6.3 Navegación

Se ha añadido un menú principal *“Veterinaria”*, desde el cual se accede a:

* Gestión de Dueños
* Gestión de Mascotas

7. Seguridad

Se han configurado permisos de acceso mediante el archivo ir.model.access.csv, permitiendo:

* Lectura
* Escritura
* Creación
* Eliminación

Esto garantiza que los usuarios puedan operar correctamente con los datos del sistema.

9. Resultados obtenidos

El módulo cumple con todos los requisitos planteados:

* Gestión completa de datos (CRUD)

* Interfaz funcional mediante vistas
* Integración con la arquitectura de Odoo

10. Conclusión

El desarrollo del módulo de veterinaria ha permitido aplicar conceptos clave de Odoo como la definición de modelos, relaciones entre entidades y creación de vistas.

La implementación de una relación One2many/Many2one entre dueños y mascotas mejora significativamente la organización de los datos y refleja un diseño más profesional y escalable.

El sistema resultante es funcional, extensible y cumple con los objetivos propuestos, siendo una base sólida para futuras ampliaciones como gestión de citas, historiales médicos o facturación.
